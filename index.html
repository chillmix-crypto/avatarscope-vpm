1VCC に追加（推奨）

下のボタンをクリックすると VCC が起動して URL が自動追加されます。

▶ Add to VCC（ワンクリック）
ボタンが効かない場合は下の URL をコピーして VCC の Settings → Packages → Add Repository に貼り付け：
https://chillmix-crypto.github.io/avatarscope-vpm/index.json

2プロジェクトにインストール

  1. VCC で対象プロジェクトの 「Manage Project」を開く
  2. パッケージ一覧に AvatarScope が表示される
  3. 右の 「+」ボタンでインストール

3使い方

  1. Unity を起動
  2. メニューバーから Tools → AvatarScope → Open Window
  3. Avatar 欄に対象アバター（VRCAvatarDescriptor 付き）をセット
  4. Refresh ボタンで解析開始
真の容量計測モード: Measure real size にチェックを入れて Refresh すると、 VRChat 実アップロード値と完全一致するダウンロードサイズが取得できます（数十秒かかります）。

4非破壊最適化（Visual Lossless）

  1. AvatarScope ウィンドウ上部の Optimize (Lossless) ボタンをクリック
  2. 候補一覧が表示されるので不要な操作のチェックを外す
  3. 選択中の操作を適用 をクリック
  4. 完了後、4方向の Before/After 画像比較ウィンドウが開く
  5. 劣化検出時は自動でロールバック、視覚劣化ゼロを保証
個別 Undo は Tools → AvatarScope → Optimization History から可能。
